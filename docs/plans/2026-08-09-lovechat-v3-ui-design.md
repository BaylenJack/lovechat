# LoveChat v3 UI 重设计

日期：2026-08-09
状态：已确认（用户批准）

## 目标

完全重写前端视觉，保留所有业务功能（消息收发/语音条/图片文件/语音通话/密码/头像/背景/动态）。

## 风格决策

| 项 | 选择 |
|---|---|
| 整体风格 | 潮流渐变（Telegram/Instagram 混合感） |
| 主色调 | 紫蓝粉渐变（夜空感） |
| 头像 | 圆形 |
| 气泡 | 圆角（12-18px） |
| 品牌名 | lovechat（替换"我们的客厅"作为主品牌） |

## 配色系统

### 主题色（紫蓝粉夜空）
- `--bg-base: #0a0b1e`（深邃紫蓝）
- `--bg-grad-1: #1a1244`（深紫）
- `--bg-grad-2: #2d1b5e`（紫）
- `--bg-grad-3: #4f1d6e`（粉紫）
- `--bg-grad-4: #1e2a78`（蓝紫）
- 背景：四色对角线渐变 + 星空噪点

### 强调色
- `--accent-1: #a855f7`（紫）
- `--accent-2: #ec4899`（粉）
- `--accent-3: #6366f1`（靛蓝）
- 主按钮渐变：`linear-gradient(135deg, #a855f7, #ec4899)`
- 我方气泡：`linear-gradient(135deg, #a855f7 0%, #ec4899 100%)`
- 对方气泡：`rgba(255,255,255,0.08)`（玻璃拟态）+ 1px `rgba(255,255,255,0.12)` 边框

### 中性色
- `--text-primary: rgba(255,255,255,0.95)`（白）
- `--text-secondary: rgba(255,255,255,0.65)`（灰白）
- `--text-tertiary: rgba(255,255,255,0.4)`（暗灰）
- `--surface: rgba(255,255,255,0.06)`（卡片背景）
- `--surface-hover: rgba(255,255,255,0.1)`
- `--divider: rgba(255,255,255,0.08)`

## 排版

- 字体：系统字体（`-apple-system, BlinkMacSystemFont, 'PingFang SC', 'Noto Sans SC', 'Microsoft YaHei'`）
- 主标题（品牌名）：32px, font-weight 700, letter-spacing -0.5px，渐变文字效果（背景裁剪 + linear-gradient）
- 副标题：13px, `--text-secondary`
- 输入框文字：15px
- 消息气泡：15px, line-height 1.5

### 聊天主界面
```
┌─────────────────────────────┐
│  ‹  (●) 对方名        🌙 ⚙️ 📞  │  ← 顶栏（玻璃态，毛玻璃背景）
```

- 顶栏：背景用 backdrop-filter blur(16px) + 半透明深色，浮动在内容之上
- 头像：圆形 36x36px
- 我方气泡：渐变背景，18px 圆角（左下角 4px，更像气泡）
- 对方气泡：玻璃拟态 18px 圆角（右下角 4px）
- 头像与气泡底部对齐

### 动态视图
- 顶部"发布"按钮（FAB 风格）+ 列表卡片
- 卡片：玻璃态，圆角 16px
- 图片网格：3 列瀑布流，点击预览

### 通话覆盖层
- 全屏 backdrop blur(20px)
- 圆形头像 120x120px（带渐变光晕边框）
- 接听/挂断按钮：圆形 64x64，带阴影

### 设置面板
- 从底部弹起的抽屉式（iOS 风格）
- 背景：玻璃态
- 头像选择：圆形预览 + 更换按钮

## 动画

- 进入过渡：所有视图切换 `transform translateY` 200ms cubic-bezier(0.16, 1, 0.3, 1)
- 消息气泡：发送时 `scale(0.8) → 1` + `opacity 0 → 1`，180ms
- 按钮：按下 `scale(0.96)` 100ms，松开回弹
- 顶栏：滚动时背景透明度渐变（0 → 0.8）
- 发送按钮：loading 状态有微旋转动画
- 动态：列表卡片进入时依次延迟 50ms（stagger）

## 微交互

- 顶栏切换按钮（动态/设置）有 hover/focus 背景亮起
- 输入框 focus 时底部边框渐变流动
- 录音按钮按下时周围有脉冲圈（紫色波纹）
- 语音条播放时有动画条形
- 通话接通瞬间全屏一个圆环扩散动画

## 实现要点

### 文件改动
- `public/index.html` —— 微调，主要是结构（div 加 class）
- `public/style.css` —— **完全重写**（从 0 开始）
- `public/app.js` —— **不动**（业务逻辑与样式无关）

### 兼容性
- 保留所有 ID 和 class 名（业务代码需要）
- 不引入新依赖（纯 CSS）
- 移动端优先（iOS Safari + Android Chrome）
- 自定义聊天背景兼容（`.msg-list.bg-custom` 类保留）

### 性能
- 渐变用 CSS 而非图片
- backdrop-filter 在 iOS Safari 兼容性已知
- 动画全部用 transform/opacity（GPU 加速）
